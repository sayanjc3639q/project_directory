# Design System

Flat solid colors only. Zero gradients. WCAG AA compliance.

## Color Tokens
### Light Theme
- Background: `#FAFAF7`
- Surface: `#F1F1EC`
- Border: `#DDDDD5`
- Text: `#1A1A1A`
- Secondary Text: `#5A5A55`
- Accent: `#1D4ED8` (hover: `#1E40AF`)
- Note Callout: `#EEF2FF`
- Warning Callout: `#FEF3C7`

### Dark Theme
- Background: `#121212`
- Surface: `#1C1C1C`
- Border: `#2E2E2E`
- Text: `#ECECEC`
- Secondary Text: `#A0A0A0`
- Accent: `#6B93F5`

## Typography
- Font: Inter via `next/font/google`
- Body: 17-18px desktop, 16px mobile. Line height 1.7.
- Reading column max width: 720px.
